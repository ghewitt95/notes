## This Week I Learned:

- When using "greater than(>)" and "less than (<)", they result in either a true or false outcomes. 

- Interpolation = the process of inserting the results of an expression into a string literal. THe way to interpolate within a string is to place the expression within #{example} symbols.

- .sub only does one solution at a time, while .gsub does multiple substitutions at once.

- Forward slashes are used to start and end an expression

- x.sub(/^../, 'Hello') means: Any two characters immediately after the start of a line will get replaced with the 'Hello'

- x.sub(/..$/, 'Hello') does the opposite, replacing the last two characters in the string.
